# Báo cáo P2-04 — MySQL → PostgreSQL: mapping kiểu, collation, múi giờ
Trạng thái: NOT DONE

## Kế hoạch
Xây dựng package `internal/typemap`, kiểm tra tương thích collation của cột khóa, mở rộng preflight validate quét dữ liệu thực tế và tích hợp vào `cmd/strand validate` theo spec/02 §8, §11, §12:
- `internal/typemap/typemap.go`: Định nghĩa `MySQLColumn`, `ColumnMapping`, `Options`, `DefaultOptions()`, và hàm `MapMySQLColumn(col, opts)`.
  - Hỗ trợ đầy đủ bảng mapping kiểu dữ liệu:
    - Số nguyên: tinyint/smallint/mediumint/int/bigint (+unsigned: unsigned bigint mặc định `numeric(20,0)`, tùy chọn `int8-checked` từ chối giá trị > 2^63-1).
    - Số thực & thập phân: decimal(p,s) -> numeric(p,s), float -> real, double -> double precision.
    - Chuỗi bit: bit(n) -> bit varying(n) hoặc bytea.
    - Chuỗi ký tự & nhị phân: char/varchar/text -> text hoặc varchar(n), binary/varbinary/blob -> bytea.
    - Ngày tháng & thời gian: date -> date, datetime(p) -> timestamp(p), timestamp(p) -> timestamptz(p) (giả định session time_zone='+00:00', trả UTC), time -> time hoặc interval, year -> smallint.
    - JSON: json -> jsonb.
    - ENUM & SET: enum -> text + CHECK (policy) hoặc enum type, set -> text[] (policy).
    - Kiểu hình học (geometry, point, linestring, polygon...): trả về lỗi exit 3 `type_unmappable`.
  - Chính sách zero date ('0000-00-00', '0000-00-00 00:00:00', ngày có tháng/ngày = 0): `reject` (mặc định, exit 3), `null`, hoặc `epoch`.
- `internal/typemap/collation.go`: Hàm `CheckKeyCollation(srcCollation, dstCollation)` kiểm tra collation cột khóa, trả exitcode `collation_looser` (exit 3) khi target lỏng hơn source (ci/ai/PAD SPACE ở target mà source phân biệt), cho phép MySQL `_ci`/`_bin` -> PG `C` hoặc deterministic; cấm `citext` trên cột khóa.
- `internal/typemap/inspect.go`: Đọc metadata cột và khóa chính từ `information_schema` của MySQL và PostgreSQL.
- `internal/typemap/validate.go`: Hàm `CheckMySQLToPGTables(ctx, src, dst, tables, opts)` quét kiểu unmappable, collation cột khóa và giá trị thực tế (zero date, unsigned bigint vượt int8 khi dùng int8-checked, ENUM ngoài danh sách) bằng truy vấn đếm có giới hạn (LIMIT).
- `internal/validate/mysql_to_pg.go`: Wrapper export `CheckMySQLToPGTables` trong package `validate`.
- `cmd/strand/validate.go`: Tích hợp `validate.CheckMySQLToPGTables` khi `source.kind=mysql` và `target.kind=postgres`.
- Test: Unit test toàn bộ các kiểu dữ liệu và case biên (`typemap_test.go`), unit test collation ít nhất 10 cặp (`collation_test.go`), và test tích hợp với testcontainers mysql:8.4 + postgres:18 (`integration_test.go`).
