# Báo cáo P1-01 — Cấu hình và khung CLI
Trạng thái: NOT DONE

## Kế hoạch
Xây dựng khung CLI `strand` sử dụng Cobra, hệ thống nạp và giải mã cấu hình YAML strict (từ chối key lạ), lệnh `strand config schema` sinh JSON Schema chuẩn theo S02 §10, bảng exit codes chuẩn (0, 1, 2, 3, 4, 5, 10), và khung lệnh `strand validate`:
- `internal/config`: Struct mô tả đầy đủ cấu hình theo S02 §10, giải mã YAML strict với `KnownFields(true)`, thay thế biến môi trường `${VAR}`, sinh JSON Schema hợp lệ cho cấu hình.
- `internal/exitcode`: Định nghĩa chuẩn các exit code theo S02 §10 và các error codes theo S02 §12.
- `internal/validate`: Khung preflight `validate` trả mã exit tương ứng khi cấu hình vi phạm.
- `cmd/strand`: Điểm nhập Cobra CLI hỗ trợ các lệnh: `validate`, `config schema`, `plan`, `sync`, `top`, v.v. Bắt lỗi cú pháp hoặc cấu hình không hợp lệ trả exit code 2.
