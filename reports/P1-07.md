# Báo cáo P1-07 — Writer ghi delta có điều kiện epoch
Trạng thái: NOT DONE

## Kế hoạch
Xây dựng cơ chế ApplyBatch của Writer ghi dữ liệu cùng row delta có điều kiện epoch theo spec/02 §4 (quy tắc 3, 6):
- Mỗi batch của writer: trong cùng transaction với dữ liệu, chạy `UPDATE _strand_worker_delta SET applied = ?, batch_no = batch_no + 1 WHERE pipeline_id = ? AND worker_id = ? AND epoch = ?`. Nếu số row bị ảnh hưởng khác 1 thì rollback và dừng với mã `fenced` (exit code 4) (AC1, TestSG1_StaleEpochRollsBack).
- Bất biến CP-1: Row delta ghi cùng transaction với dữ liệu; nếu kill hoặc rollback thì cả dữ liệu và delta đều không được ghi; nếu commit thì delta chứa đúng Txn vừa ghi (AC2, TestCP1_DeltaSameTxn).
- Cột `batch_no` luôn tăng giúp câu lệnh UPDATE luôn làm thay đổi dữ liệu row delta trên đĩa, do đó MySQL driver dù không bật cờ `clientFoundRows=true` vẫn trả về `RowsAffected() == 1` một cách chính xác (AC3, TestAC3_MySQLClientFoundRows).
