# Quyền sở hữu spill khi replay prefetch — 2026-11-08

Spool STX2 ghi đường dẫn tới file spill thay vì chứa payload. Trước sửa, router xóa file input sau khi đọc nhưng trước Admit và trước target commit. Nếu dừng ở cửa sổ đó, metadata spool vẫn trỏ vào file đã mất; lần replay sau lỗi ENOENT, có thể không còn nguồn phục hồi nếu binlog/archive đã bị xóa. Đây là lỗi mất khả năng replay, không có bằng chứng checkpoint tự tiến hoặc mất dữ liệu âm thầm.

File mới của assembler và router có quyền sở hữu tạm trong RAM; file decode từ spool mặc định là reference bền mượn, không serialize quyền này vào STX2. Spool nhận quyền giữ reference khi enqueue segment hoặc ngay trước commit Pebble (lỗi commit I/O có thể mơ hồ), caller chỉ được dọn nếu vẫn sở hữu. Router tạo file dẫn xuất tại runtime spill dir riêng, giữ input mượn qua mọi đường; xóa output của mình nếu Admit/Persist thất bại. Không đổi source position, checkpoint hay thứ tự transaction (CP-1/2, SD-1..4, CO-1/2). Prefetch được xóa như cũ chỉ sau routed count và scheduler LWD xác nhận đã apply.
