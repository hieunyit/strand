# Báo cáo P1-18 — Admin socket và lệnh vận hành
Trạng thái: NOT DONE

## Kế hoạch
Hiện thực module `internal/admin` (UNIX domain socket server & client) và các lệnh vận hành CLI theo spec/02 §10:
1. Giao thức IPC qua UNIX domain socket:
   - Server lắng nghe tại đường dẫn socket (mặc định `/run/strand/<pipeline>.sock` hoặc cấu hình qua flag/config).
   - Truyền nhận message định dạng JSON có cấu trúc Request/Response.
2. Các lệnh vận hành:
   - `top`: Lấy thống kê thời gian thực (lag, throughput, governor zone, tiến độ, ETA).
   - `pause`: Tạm dừng pipeline cdc.
   - `resume [--snapshot-only]`: Chạy tiếp pipeline; cờ `--snapshot-only` chỉ cho phép snapshot chạy, hoãn stream.
   - `throttle set --source-iops <n> --soft`: Đổi nóng giới hạn tốc độ/tài nguyên mà không cần khởi động lại tiến trình.
   - `checkpoint show`: Xem vị trí checkpoint hiện tại (GTID / LSN, epoch, applied set).
   - `checkpoint rewind --to <pos>`: Tua lại checkpoint đến vị trí xác định, có kiểm tra tính hợp lệ (`gtid_purged` / `restart_lsn`).
3. CLI tích hợp trong `cmd/strand`:
   - Các lệnh con `top`, `pause`, `resume`, `throttle set`, `checkpoint show|rewind` kết nối tới admin socket tương ứng.
