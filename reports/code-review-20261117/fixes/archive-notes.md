S04/S05: archive reader now rejects PARTIAL_UPDATE_ROWS_EVENT before commit, including inside compressed transaction payloads; it recursively handles valid TRANSACTION_PAYLOAD_EVENT children. It rejects undecoded GTID, query, table map, rows and XID events, malformed or nested payloads, and anonymous GTID/incident/XA-prepare events. Handler errors retain their classified exit code through ParseFile.

TABLE_MAP must have complete, distinct column names and a valid primary key. Prefetch's assembler otherwise falls back to the first column; it has no schema/keyless resolver. Consequently archive prefetch currently fails closed for genuinely keyless and unique-only tables, and for unrelated tables with missing metadata as the archive reader sees every table. Full or partial row events with any skipped column are rejected using go-mysql's SkippedColumns, since decoded rows retain full length and represent both skipped and SQL NULL columns as nil. Missing TABLE_MAP and malformed row widths/update pairs also fail closed.
