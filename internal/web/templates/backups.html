Restore

A restore always goes to a new target: a database that does not exist yet (logical backups) or an empty directory (pg_basebackup). Choose a backup, or a source and a point in time: Strand picks the base backup and replays archived logs up to that time. Progress and log appear on the job page.

Repositories

Endpoints and credentials stay in the Web service environment: a repository names its variable prefix (STRAND_BACKUP_REPO_<NAME>_ENDPOINT, _ACCESS_KEY, _SECRET_KEY, ...). Object Lock repositories make every new object immutable for the given days (the bucket must be created with Object Lock).
