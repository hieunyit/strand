Scheduled backup jobs

Jobs run a native backup wrapper on the Strand Web host, publish its artifact and seed manifest to S3, and can open a verified SSH tunnel for the database. Configure S3 credentials and database secrets in the Web service environment; do not put passwords in scripts' command-line arguments. Saving an enabled job schedules its first run immediately; its next run is persisted across Web restarts.
