MCP (Model Context Protocol)

strand mcp is a read-only MCP server over stdio. Your MCP client (Claude Desktop, Claude Code, an IDE) starts it on a machine that has the strand binary and can reach this web's PostgreSQL metadata database; the web does not run it. Every tool call is written to the audit log as mcp.<tool>.
