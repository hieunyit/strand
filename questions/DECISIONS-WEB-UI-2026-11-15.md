# Quyết định của owner — 2026-11-15 (Web UI, kéo từ P4 lên)

Nguồn: `docs/PLAN-WEB-UI.md` (kế hoạch) và các câu trả lời của owner cho mục 7 của kế hoạch. Không sửa `spec/`; cột cuối ghi chỗ spec owner cần cập nhật.

| # | Quyết định | Code | Spec owner cần sửa |
|---|---|---|---|
| W1 | Web UI được **kéo từ P4 lên làm trước**. Làm theo mốc M0–M5 của kế hoạch; đợt này giao M0 + M1 + M2 (khung, bảo mật, trang chỉ đọc). M3–M5 (thao tác, wizard repair/promote, sửa cấu hình/tạo pipeline) do đợt sau, nhờ điểm mở rộng đã để sẵn (`ActionRegistry`, `JobRunner`) | `internal/web`, `cmd/strand/web.go` | 01 §5 (bảng phạm vi): Web UI chuyển từ P4 sang sớm hơn; 06 (ADR): package mới `internal/web` |
| W2 | **Package mới `internal/web`** (lệnh `strand web`) theo spec 06 §1 phải có ADR: ADR này. Frontend là `html/template` + một file JS tay viết (fetch + làm mới định kỳ, header CSRF) + CSS, nhúng bằng `go:embed`. **Không** thư viện JS ngoài (bỏ htmx, uPlot trong kế hoạch), không tải gì qua mạng. Biểu đồ là SVG render phía server từ ring buffer trong RAM. Dependency mới duy nhất: `golang.org/x/crypto` (bcrypt, đã có trong `go.mod` gián tiếp) và `golang.org/x/term` (đọc mật khẩu không echo); cả hai thuộc tiền tố `golang.org/x/` của `deps.allow` | `internal/web/{templates,static}`, `go.mod` | 06 §7 (`deps.allow`): không đổi |
| W3 | Quản lý pipeline hỗ trợ **hai chế độ**: (a) systemd `strand@<name>` với cấu hình `/etc/strand/*.yaml` (+ `<name>.env`); (b) chế độ nền sẵn có của CLI: `strand sync -c <cfg> --background`, `strand stop -c`, `strand status -c` (pid và log mặc định `<resources.spool.path>/strand.pid\|strand.log`). Pipeline được đăng ký trong `web.yaml`: `scan: [glob...]` và/hoặc `pipelines: [{name, config, env_file?, systemd_unit?}]` (cộng `log_file`, `pid_file` tùy chọn). Có `systemd_unit` (hoặc cấu hình đến từ scan và unit `strand@<name>` tồn tại) thì dùng systemctl/journalctl; ngược lại dùng lệnh nền và file log. Khai báo tường minh thắng scan cùng tên. Tên pipeline qua whitelist `^[A-Za-z0-9][A-Za-z0-9_.-]{0,62}$` | `internal/web/pipelines.go`, `config.go` | 03 §4 (vận hành): ghi nhận hai chế độ |
| W4 | `strand web` chạy **cùng user chạy strand, không phải root**. Không polkit, không sudo. Hệ quả: chỉ quản lý được pipeline mà user đó có quyền (đọc file cấu hình và `.env`, kết nối admin socket 0700 cùng user, đọc log; `journalctl` cần user thuộc nhóm `systemd-journal`; `systemctl start/stop` là việc của M3 và chỉ chạy được nếu hệ thống cho phép). Điểm 1 ở mục 7 của kế hoạch (root) bị thay bằng quyết định này | `packaging/strand-web.service` (`User=strand`) | 03 §4 |
| W5 | **Bảo mật** (kế hoạch mục 4): một tài khoản admin, mật khẩu bcrypt trong `web.yaml` 0600 (`strand web passwd`), không có mật khẩu thì không khởi động; session 256 bit trong RAM, cookie `HttpOnly`, `SameSite=Strict`, `Secure` khi có TLS; hết hạn 30 phút không dùng / 12 giờ tối đa; CSRF token cho mọi POST của session (đăng nhập dùng cookie đôi); giới hạn đăng nhập sai 5 lần/phút/IP rồi khóa tăng gấp đôi (1, 2, 4… tối đa 15 phút); TLS bắt buộc trừ khi bind loopback; header `CSP default-src 'self'`, `X-Frame-Options DENY`, `Referrer-Policy no-referrer`, `nosniff`; token API tĩnh tùy chọn (lưu sha256, `strand web token`), dùng Bearer, không cần CSRF vì không dùng cookie | `internal/web/{auth,server}.go` | — |
| W6 | **Audit log** dạng JSON lines `<state_dir>/audit.log` (0600): `time`, `ip`, `action`, `pipeline`, `args`, `result`, `exit_code`. M2 ghi: đăng nhập (đúng/sai/bị chặn), đăng xuất, CSRF bị từ chối, xem cấu hình. Thao tác ghi của M3+ phải ghi dòng `started` TRƯỚC khi chạy và không chạy nếu không ghi được audit | `internal/web/audit.go`, `actions.go` | — |
| W7 | Ba lệnh **admin socket chỉ quan sát** thêm vào `strand sync` (kế hoạch mục 5): `status`, `tables`, `events` (ring 200 bản ghi WARN/ERROR qua slog handler bọc ngoài, log hiện có không đổi). Giao thức cũ giữ nguyên: handler cũ trả "not supported"; không đụng reader/scheduler/writer/checkpoint | `internal/admin`, `internal/pipeline/admin_observe.go`, `cmd/strand/sync.go` | 02 §10 (bảng admin socket): thêm ba lệnh |
| W8 | Phạm vi M2: pipeline đã dừng chỉ hiện trạng thái (systemctl show: ActiveState, ExecMainStatus; hoặc file pid) và đuôi log; **không** đọc vị trí checkpoint từ target khi pipeline dừng (đắt, cần mật khẩu). Mẫu 5 giây từ admin socket và `/metrics` vào ring buffer 1 giờ (720 điểm) trong RAM | `internal/web/sampler.go` | — |
